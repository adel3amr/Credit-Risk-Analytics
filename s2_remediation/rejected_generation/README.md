# Pre-fit generator defect, retained evidence

During code review, before fitting any model or reading any outcome metrics,
the short 12-quarter calibration/promotion histories were found to traverse only
the start of a 40-quarter cycle. They omitted downturn/recovery phases.
This is a generator coverage defect, not an unfavorable performance result.
The original generator and all generated files/hashes are preserved here.
No model was fitted on this attempt; no promotion outcome was inspected.

Correction: short synthetic audit cohorts traverse all five cycle phases over
their allotted quarters. The 240-quarter development history is unchanged.
The numerical gates, candidate specification, source borrower separation and
recovery equations are unchanged. This single correction precedes candidate
freeze. Subsequent generation is the accepted dataset, not a performance retry.
