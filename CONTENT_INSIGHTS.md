# Evidence-based content insights

1. Near-zero aggregate LGD bias concealed opposing errors in cure and severe-loss groups. Report denominators and forecast-selected cohorts alongside retrospective tails.
2. Better synthetic RMSE did not make a challenger deployable: security/guarantor quality inputs were absent from live scoring.
3. A model artifact is insufficient lineage. Source date, knowledge date, source hash, policy/scenario version, run and decision trace are needed together.
4. Watchlist, SICR, Stage2 and default remain separate concepts. The nine-month persistence rule is internal project policy.
5. Source monetary rounding can prevent exact replay from displayed face amounts. Preserve and report the reconciliation bound instead of adjusting numbers to force equality.
6. Backend authorization and a visual role selector provide different evidence. This release tests backend denials.
7. A research archive can be intact in Git while a working CSV is truncated. Hash validation must precede model work.
8. SQLite/API tests and a container specification do not prove a PostgreSQL deployment. Keep operational verification visible.
