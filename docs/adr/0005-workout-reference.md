# ADR 0005 — Additive dated workout research and shared evidence

Context: historical flat facility LGD and MI experiments leave workout lineage, feature availability and calibration limitations. Existing active policy is frozen.

Alternatives: overwrite historical datasets; replace active LGD immediately; microservice; isolated notebook; additive modular research domain.

Decision: use an additive WN-1 relational namespace, frozen prospective datasets, fixed direct/component comparison, independent ledger validation and authenticated evidence integration. Keep component model blocked; use one service aggregation for dashboard and Copilot. Restrict external narrative release to deterministic evidence rendering.

Consequences: preserves historical reproducibility and avoids fabricated joins. WN-1 Stage 3 cohort ECL is separate from the active portfolio. More expressive storage does not solve empirical calibration, censored outcomes or remaining-security modelling. PostgreSQL and deployed operational qualification remain separate evidence requirements.
